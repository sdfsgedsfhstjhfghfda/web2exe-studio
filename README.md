# 🚀 Web2Exe Studio (Web Sitelerini Windows EXE'ye Dönüştürücü) UYARI: .ZİP KLASÖRÜNÜ İNDİRDİKTEN SONRA MASAÜSTÜNDE TÜMÜNÜ AYIKLA SEÇENEĞİNİ SEÇİP AYIKLAYIN AKSİ TAKDİRTDE PRGRAM ÇALIŞMİCAKDIR

> **Herhangi bir HTML sayfasını, web projesi klasörünü veya ZIP arşivini tek tıkla taşınabilir (Portable) bir Windows `.exe` masaüstü uygulamasına dönüştüren akıllı stüdyo.**

---

## 🌟 Temel Özellikler

1. 📂 **Sürükle & Bırak Desteği:**
   - Web dosyanızı, klasörünüzü veya `.zip` arşivinizi doğrudan pencereye sürükleyip bırakabilirsiniz.
   - Dosya / Klasör seçme butonları ile bilgisayarınızdan kolayca dosya seçebilirsiniz.

2. 📜 **Belirgin Kurallar & Desteklenen Dosyalar Rehberi:**
   - Arayüzde daima görünür desteklenen dosya türleri:
     - ✅ **`.html` / `.htm`**: Tekil web sayfaları.
     - ✅ **Web Klasörleri**: İçinde `index.html`, CSS, JS ve resimler olan tüm web projeleri.
     - ✅ **`.zip` Arşivleri**: Web sitenizi içeren zip dosyaları.
     - 🚫 **Desteklenmeyenler**: `.mp4`, `.docx`, `.pdf`, `.exe` vb. durumunda *"Dosyanın türü bunu karşılamıyor"* uyarısı verilir.

3. 🛡️ **Kendi Kendini Düzenleyen ve Hata Düzelten Yapı (Self-Healing):**
   - Kullanıcı sadece bir `.html` dosyası verse dahi, eksik olan `package.json`, `main.js` ve pencere ayarlarını **tamamen kendisi otomatik üretir**.
   - Göreceli dosya yollarını ve karakter kodlamalarını (UTF-8) optimize eder.

4. 🎛️ **Özelleştirme:**
   - Uygulama adı belirleme.
   - Pencere boyutu (1280×800, 1920×1080 Akıllı Tahta, Tam Ekran Kiosk modu).
   - Menü çubuğu gizleme.
   - Çıktı konumunu seçme (Varsayılan: Masaüstü).

5. ⚡ **Canlı Derleme Konsolu:**
   - Derleme aşamalarını adım adım ve terminal loglarıyla canlı gösterir.
   - Bitince doğrudan *"Uygulamayı Hemen Başlat"* veya *"Klasörde Göster"* seçenekleri sunar.

---

## 🚀 Nasıl Başlatılır?

1. `Web-to-EXE-Studio` klasöründeki **`start.bat`** dosyasına çift tıklayın.
2. Web dosyanızı veya klasörünüzü sürükleyip bırakın.
3. **"WINDOWS UYGULAMASINA DÖNÜŞTÜR (.EXE)"** butonuna basın!
